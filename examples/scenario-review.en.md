This is an authored synthetic walkthrough, not an autonomous agent evaluation or a client case.

The client wants to import two agreed spreadsheet formats, review exceptions and export an approved result. An operator still confirms the output. The business system has not been built by this repository; the demonstration shows how a project is understood and planned.

The written request and buyer clarification support the phase-one boundary. An AI meeting summary suggests cloud permission and automatic payment, but neither is an authorized decision. The payment suggestion conflicts with the written exclusion; it must not enter the phase-one scope. Deployment remains a tracked question for customer IT.

OCR is a candidate, not a demonstrated capability. Obtain representative images and scoring rules before promising quality, deployment capacity or cost. The team can independently research and compare suitable libraries and models; customer-only samples and permissions still require the customer.

The proposed structure is intake → deterministic parsing/validation → exception review → approved export, with source and rule versions preserved. This is an architectural suggestion. Detailed technology, data protection, integration and acceptance need confirmation; no live system or production result is asserted.

The linked register contains four requirements, four pending acceptance items and six work packages. Effort is purely synthetic: 7.5 / 13 / 23 person-days. No role rates or budget exist, so complete labor cost is unknown. These scenarios do not establish delivery duration or selling price.

Before a real commitment, clarify deployment permission, representative data, rule owners, target acceptance, test environment and available personnel. A concise client request should explain why each item affects architecture, verification or scope. Do not ask a nontechnical owner to judge whether a library will work when the team can investigate it.

The plan record check can pass while business acceptance remains pending. The handover check must fail. That distinction is the intended teaching outcome.
